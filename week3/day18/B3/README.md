# Bloque 3 (Day18) — GitHub Actions Workflow

En este bloque se creó el primer **workflow de GitHub Actions** para el proyecto `bootcamp-remote`.

## Objetivos
- Configurar un workflow que se ejecute en cada `push` o `pull request` a `main`.
- Instalar Python 3.12 y las dependencias necesarias (`pytest`, `psycopg2-binary`).
- Ejecutar automáticamente los tests de la carpeta del Bootcamp.
