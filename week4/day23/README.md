# Day 23 — Descriptive Statistics & Mini EDA

## Overview
This day focused on combining **basic statistics** and **data visualization** to perform a first exploratory analysis (EDA).  
The goal was not only to practice coding, but also to understand how these tools are used in real-world data analysis.

---

## B1 — Descriptive Statistics with Pandas
- Calculated **mean, variance, and correlation** using `pandas`.
- Interpreted results in a business context (sales vs. expenses).
- Learned how these metrics describe data distribution and relationships.

---

## B2 — Visualization with Matplotlib & Seaborn
- Practiced creating different types of plots:
  - Histogram (distribution of values)
  - Scatter plot (relationship between two variables)
  - Heatmap (correlation matrix)
- Focus was on **learning the syntax** and saving plots as `.png` files.

---

## B3 — Mini Exploratory Data Analysis (EDA)
- Combined descriptive statistics and plots in one workflow (`eda.py`).
- Simulated a **basic professional analysis**:
  - First look at the dataset
  - Descriptive statistics
  - Visual exploration of relationships
- Difference from B2: not just “drawing charts”, but **using them as part of an analysis process**.

---

✅ This structure closes Day 23 with a solid understanding of how to move from raw numbers to visual insights.
